🪽 윙 닷지 3D

사방에서 조여오는 장애물을 피하는 비행 아케이드

조작법

  • 화면 터치 / 스페이스바 — 날갯짓해서 위로 상승
  • 화살표 버튼·방향키 / 폰 기울이기 — 좌우 이동
  • ✨ 버튼 / Shift — 새의 고유 스킬 사용

공략 팁

장애물은 바닥·천장·양옆 네 방향에서 모두 나옵니다. 화면 가운데 높이를 유지하면 위아래 어느 쪽 장애물에도 대응할 시간이 생깁니다. 별은 무리해서 먹지 말고 경로에 자연스럽게 걸리는 것만 챙기는 것이 오래 사는 비결입니다.

새마다 스킬이 다릅니다 — 병아리는 충돌 1회를 막는 알 껍질 방패, 참새는 몸 축소(좁은 틈 통과), 제비는 별 자석, 부엉이는 슬로모션, 독수리는 전방 장애물 파괴입니다. 초보라면 실수를 용서해 주는 병아리, 점수 욕심이 있다면 부엉이를 추천합니다.

월드는 숲 → 신전 → 유리창 → 백룸 순서로 열립니다. 이전 월드에서 목표 점수를 달성하고 별을 모으면 해금됩니다. 스마트폰은 가로 화면이 시야가 넓어 유리합니다.

🔴 3D 바운스볼

별을 모두 모아 EXIT까지 — 스테이지 클리어 액션

조작법

  • WASD / 드래그 조이스틱 — 이동 (공은 자동으로 튕깁니다)
  • ← → / ⟲⟳ 버튼 — 화면 90° 회전, ↑↓ — 줌
  • Shift / 🗺️ 버튼 홀드 — 맵 전체 내려다보기
  • 스페이스 / USE 버튼 — 보유한 아이템 사용

공략 팁

가시에 닿으면 즉사하고 스테이지 처음부터 다시 시작합니다. 서두르지 말고 🗺️로 맵 전체를 먼저 살펴 별 위치와 경로를 그려보세요.

노란 아이템은 대시(7칸 도약)·점프(더 높이)·워프·귀환 마커 중 하나입니다. 귀환 마커는 한 번 누르면 설치, 다시 누르면 그 자리로 순간이동 — 허공에 뜬 별을 뛰어내려 먹고 추락하기 전에 귀환하는 식으로 씁니다. 점프 아이템은 공중에서도 쓸 수 있어 사실상 2단 점프입니다.

3칸짜리 넓은 공백은 그냥 뛰면 못 넘습니다 — 직선 조주로에서 속도를 붙인 채 뛰어야 합니다. 파란 벽은 점프 아이템으로만 넘을 수 있고, 움직이는 발판은 위에 올라타면 함께 이동하는 페리입니다. 튜토리얼 10스테이지에서 기믹을 하나씩 배우고 모험 월드에 도전하세요.

☁️ 스카이 바운스 3D

쉴 새 없이 튀는 공을 조종해 하늘 끝까지 — 무한 상승 아케이드

조작법

  • 방향키·WASD / 드래그 — 공을 좌우·앞뒤로 조종 (점프는 자동)

공략 팁

공은 계속 튀고 있으므로 "착지할 발판"이 아니라 "다음 발판"을 보고 미리 움직이는 것이 핵심입니다. 화면 아래로 떨어지면 끝이니 항상 위쪽 발판 배치를 먼저 읽으세요.

높이 올라갈수록 발판이 좁아지고 간격이 벌어집니다. 무리해서 최단 경로로 오르기보다, 넓은 발판을 징검다리 삼아 안정적으로 오르는 쪽이 결과적으로 더 높은 기록을 만듭니다. 최고 기록은 브라우저에 저장되니 어제의 나와 경쟁해 보세요.
